Qanopy

An open, independently checkable way to see whether a forest carbon credit project is delivering what it claims — using free satellite data that anyone can re-run.

Why this exists

A company pays a landowner not to cut down a forest, and receives carbon credits in return. Each credit represents one tonne of CO2 that was supposedly never released.

But the credit counts trees that would have been cut down. Checking a claim like that means comparing the project against similar unprotected land nearby — and today that comparison lives inside paid dashboards. When a result turns out unfavourable, nobody is obliged to publish it.

Verra’s own review of its Kariba project found more than half the credits issued did not represent real climate impact. Companies had already counted them toward public climate targets.

What we found

We ran the pipeline on Fazenda Pacajá, a 146,427-hectare REDD+ project in Pará, Brazil, which began on 14 December 2017.

 ClaimedMeasured
Avoided deforestation2,770 ha/yr770 ha/yr
CO2e over the window6.8 Mt1.9 Mt

Our estimate accounts for roughly 28% of the project’s own projection — a gap of about 3.6×.

This is a first estimate, not a verified result. We are not alleging that this project is fraudulent. We are showing that a gap of this size currently sits where nobody outside a paid platform can inspect it.

Three reasons our own number could be wrong

Frontier exposure

Our comparison plots sit nearer the advancing clearing front than the project does. That flatters the project and inflates our estimate.

A few plots dominate

A handful of comparison plots with very large losses carry the average. The 95% interval runs from 2,606 to 8,136 hectares.

A two-year blind spot

Radar alerts begin in 2020, so 2018 and 2019 are missing. That cuts the other way and understates us.

Every one of these ships with the result. A number you can argue with is worth more than a number you cannot see.

How it works

  • 1 · Find twin forestsSatellite data finds unprotected land that matched the project before it started.
  • 2 · Select the set50 of 200 plots, balancing match quality against geographic spread.
  • 3 · Freeze and hashThe chosen set is locked with a SHA-256 hash before monitoring begins, so it cannot be swapped later.
  • 4 · Monitor weeklyRADD radar alerts track forest loss in the project and in every frozen plot.

The quantum part, honestly

Choosing the comparison set is a subset-selection problem with a quadratic term, so we wrote it as a QUBO and ran it on IBM’s 156-qubit ibm_fez processor. On an 8-qubit version it found the optimal set in 70.8% of valid shots, against 1.8% for random guessing.

Classical solvers still beat it at every size we can run, and that was a favourable problem instance. We publish that too. Scaling to the full selection would need two-qubit gates roughly 200× more accurate than today’s. The value of the quantum work right now is a validated formulation and an honest benchmark — not a claim of advantage.
