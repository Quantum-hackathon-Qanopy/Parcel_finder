Where the loss happened

Each square is a 2 km grid cell, coloured by the share of its forest lost so far. Comparison parcels have a blue outline; project cells are the small squares inside the project. The red line is the project boundary, which the grid only partly covers; the yellow band is the leakage buffer. Use the layer menu on the map to switch zones and features on and off. Drag the slider or press play.

Add a project

Upload the boundary and enter the project's facts. The pipeline checks it, finds comparison parcels, monitors it and, if you choose, publishes the status to the NFT. A run takes about 20 to 40 minutes.
